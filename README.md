# 알바 급여 자동 계산기 (v1.0)

> **"한 달 = 4.34주" 가정을 쓰지 않는 진짜 달력 기반 알바 급여 계산기**  
> 5인 미만 / 5인 이상 사업장 구분, 요일별 시급 차등, 수습 감액 게이트, 주차별 계산 근거 투명 공개

---

## 🌟 주요 특징 및 차별점

1. **진짜 달력 기반 계산**:
   - `4.34`주, `209`시간 같은 고정 가정을 배제하고, 대상 연/월 달력에서 실제 일한 날짜와 근무 횟수를 기준으로 정확하게 계산합니다.
2. **5인 미만 / 5인 이상 사업장 구분**:
   - 상시 근로자 수 선택을 강제하여 5인 미만 사업장의 가산수당 제외(통상임금 1.0배)와 5인 이상 사업장의 법정 가산(연장·야간·휴일 50%)을 정확히 분기합니다.
3. **요일별 근무시간 & 시급 차등 완벽 지원**:
   - 평일과 주말 시급이 다른 경우, 주휴수당 산정 시 반드시 **가중평균시급**을 산출하여 법적 기준에 부합하게 계산합니다.
4. **수습 감액 게이트 로직**:
   - 1년 미만 단기 계약 또는 편의점·카페·서빙 등 단순노무 직종의 불법적인 10% 감액을 원천 차단하고 안내 배너를 제공합니다.
5. **사장님 제출용 주차별 계산 근거 (아코디언)**:
   - 주차별 실근로시간, 주휴 발생 여부와 구체적 사유(15시간 미만, 결근 등), 월 경계 안분 비율을 상세히 보여줍니다.
6. **범용 데이터 가져오기 (CSV / 엑셀 복사-붙여넣기)**:
   - 엑셀이나 구글 시트에서 복사한 근무 기록을 1초 만에 붙여넣어 일괄 계산합니다.
7. **계산 결과 URL 공유**:
   - 서버 저장 없이 현재의 모든 설정과 근무표를 URL에 인코딩하여 링크 하나로 전달합니다.

## 🛠️ 기술 스택

- **Core**: React 18, TypeScript, Vite, Tailwind CSS
- **Utility**: `date-fns` (정밀 날짜 및 주 경계 연산), Lucide Icons
- **Testing**: Vitest (명세서 §7 검증 체크리스트 39개 케이스 100% 통과)
- **배포**: Cloudflare Pages / Workers 또는 Static Web Hosting
